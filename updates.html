Current release

Version 1.4.2

26 July 2026

Tutorial 02 — end-of-input section kept within the current syllabus

  • Removed the file-stream material from the new end-of-input section, since data files come later in the learning path.
  • Replaced it with keyboard and redirected-input examples: reading words with while (scanf("%99s", word) != EOF), and reading whole lines with while (scanf(" %99[^\n]", line) != EOF).
  • Documented why the leading space is mandatory in the scanset form, with a verified run of the infinite loop that results without it.
  • Left feof and ferror as a short forward pointer to the data-files topic rather than a worked example.
  • Removed the D13 Data Files tutorial link added in 1.4.0, since file error detection is no longer taught in that section.

Code sample legibility

  • Turned off the JetBrains Mono programming ligatures, which were drawing != as a slashed equals, >= as a single glyph, and -> as an arrow. The source characters were always correct; only the rendering was misleading.
  • Replaced the remaining non-ASCII characters inside code samples so that everything a reader copies is plain, portable C source.

Back-to-top control

  • Added a floating back-to-top button to every page, appearing once the reader scrolls past 400 pixels.
  • Gave it an accessible label, keyboard focus styling, and focus movement to the page heading after scrolling.
  • Hid it while the mobile navigation drawer is open, and made it respect the reduced-motion preference.

Previous release

Version 1.4.1

26 July 2026

Tutorial 04 — shift-count rules

  • Documented the valid range of a shift count: 0 up to one less than the bit width of the promoted left operand.
  • Recorded that a negative count, or one at or beyond that width, is undefined behavior, with verified evidence that the results are silently wrong rather than diagnosed.
  • Separated the two related rules: a negative left operand of << is undefined, while a negative left operand of >> is implementation-defined.
  • Noted that integer promotion sets the width, so a short operand is limited by int rather than by its own type.
  • Added a checklist row, a quick-reference note, and Exercise 12 on classifying shift expressions.

Version 1.4.0

26 July 2026

Tutorial 04 — new section on lvalues

  • Added Section 03: Lvalues and rvalues, placed before compound assignment.
  • Explained the object-versus-value distinction, modifiable and non-modifiable lvalues, and lvalue conversion.
  • Listed which operators require a modifiable lvalue, which require any lvalue, and which produce one.
  • Added the GCC and Clang error wordings for each lvalue mistake, and a new classification exercise.
  • Renumbered the later sections; the tutorial now has 18 sections.

Tutorial 02 — new section on end of input

  • Added Section 11: End of input and EOF, placed after formatted input.
  • Explained EOF as a negative int sentinel rather than a character, and why the result must be stored in int.
  • Documented how to signal end of input from a terminal, a redirected file, and a pipe.
  • Separated the three scanf return values, and showed how to recover from a matching failure instead of looping forever.
  • Added feof and ferror, and demonstrated with a verified run why while (!feof(fp)) processes the last line twice.
  • Renumbered the later sections; the tutorial now has 18 sections.

Topic-list connections

  • Added the lvalue topic to D01 and connected it to the new section.
  • Connected the character-I/O and input-validation topics of D04 to Tutorial 02.
  • Connected D13 Data Files to Tutorial 02 for end-of-file handling and file error detection.
